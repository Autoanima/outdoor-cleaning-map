名單加密工具

同學姓名會加密後存在 js/roster.enc.js，GitHub 上只看得到亂碼。這個工具在你的瀏覽器裡運作，不會把名單傳到任何地方。

1. 解開目前的名單

2. 修改名單

owners 的代號（例如 L-glass-w1）要和 js/map-data.js 裡的 id 一樣；supervisors 對應區段 id。

3. 設定密碼並產生加密檔

  1. 到 GitHub 的 repository，打開 js/roster.enc.js，按鉛筆圖示編輯。
  2. 全部刪掉，貼上剛剛複製的內容，按 Commit changes。
  3. 約一分鐘後網頁更新。改了密碼的話，每支手機要重新輸入一次。
