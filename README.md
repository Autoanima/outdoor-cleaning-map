# 外掃區檢查地圖

手機用的外掃區清潔檢查網頁。點地圖上的物件就能記錄清潔程度（好／不好／未出席）、標記「有狀況」、拍照上傳到 Google 雲端硬碟，並依紀錄彙整報表、通知同學，也會寫入 Google 試算表作為加扣分的依據。

- 純靜態網頁，可直接放在 **GitHub Pages**
- 後端使用 **Google Apps Script**（免費，資料存在你自己的 Google 帳號）
- 不設定雲端也能使用：紀錄只存在手機上

## 功能

| 功能 | 說明 |
|---|---|
| 長條地圖 | 走廊轉成直的，手機上下滑動。上＝南、下＝北、右＝西側（垃圾子車區）、左＝東側（國中部區）。兩側紫色長條是水泥平台。物件依種類編號（公佈欄玻璃 1、2、3…） |
| 點選物件 | 點了才顯示物件名稱與負責同學，可記錄「好／不好／未出席」 |
| 有狀況 | 打開開關並寫下說明，地圖上會出現紅色閃爍外框和「!」旗標；上方的紅色標籤可以逐一跳到每個有狀況的地方 |
| 照片 | 手機端先壓縮（最長邊 1600px，約 150–300 KB）再上傳，小圖顯示在牆外空白處，點一下就能全螢幕檢視（可左右滑動） |
| 報表 | 按右下角指南針的「匯出報表」：統計、需改進名單、有狀況清單；按「傳送 LINE 通知」會開啟分享並確認「不好」的紀錄都已寫入試算表 |
| 自動清空 | 從第一次標記開始算，20 小時後自動清空手機上的紀錄（試算表與雲端硬碟裡的資料會保留） |
| 離線可用 | 沒有網路時先存在手機裡，恢復連線後會自動補傳 |

右上角的圓點代表同步狀態：灰＝未設定雲端、綠＝都已寫入、黃＝等待寫入、藍＝寫入中、紅＝失敗（點一下可重試）。

## 一、放到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `outdoor-cleaning-map`），把這個資料夾的所有檔案上傳。
2. 到 repository 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 大約一分鐘後，網址會是 `https://你的帳號.github.io/outdoor-cleaning-map/`。用手機打開後，可以「加到主畫面」。

## 二、連接 Google 試算表與雲端硬碟

1. 建立一份新的 Google 試算表（例如「外掃檢查紀錄」）。
2. 選單 **擴充功能 → Apps Script**，把 [`gas/Code.gs`](gas/Code.gs) 的內容整份貼上，取代原本的程式碼。
3. 修改最上方的 `CONFIG`：`TOKEN` 就是網頁的開啟密碼
4. 上方函式選單選 `setup`，按「執行」，依畫面完成授權（會出現「Google 尚未驗證這個應用程式」，點「進階 → 前往」即可，這是你自己的腳本）。
   執行後試算表會有「扣分統計」「檢查紀錄」「工作分配」三個工作表，「扣分統計」上會有計算扣分的按鈕。
5. 右上角 **部署 → 新增部署作業**：
   - 類型：網頁應用程式
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 把網址填進 [`config.js`](config.js) 的 `gasUrl`（目前已填好）。

> 之後若修改 `Code.gs`，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本** 才會生效。

**密碼（TOKEN）不要寫進 GitHub 上的檔案**，`Code.gs` 只貼在你自己的 Apps Script 裡；GitHub 上的 `gas/Code.gs` 是範本。

## 試算表內容

- **檢查紀錄**：只記錄「不好」的處所，「好」和「未出席」不記錄。欄位：日期、處所、負責同學、說明（有狀況會標【有狀況】）、照片（可直接點「照片1、照片2…」打開）、檢查人。同一次檢查中若改回「好」，那一列會自動刪除。
- **扣分統計**：列出全班同學（依名單的科別、座號順序，沒被扣分的顯示 0，有扣分的整列標淺紅色）。按「▶ 計算扣分」按鈕（手機 App 上改勾選 B6 的方塊，或用選單「外掃檢查 → 計算扣分」），就會加總每位同學「不好」的次數與扣分，並列出每一次不好的日期（同一天有好幾處會寫成 9/23(2)；處所、說明、照片請看「檢查紀錄」）。可設定每次扣幾分，以及起始／結束日期。同一天、同一處、同一人只算一次。
- **工作分配**：人員設定的結果。

## 登入、使用人與人員設定

- 打開網頁先輸入**密碼**，再從下拉選單選**使用人**（導師或兩位檢查人）。每支手機只要登入一次。
- 密碼就是 `gas/Code.gs` 裡的 `TOKEN`。要改密碼：改 `TOKEN` 後重新部署。
- **人員設定**：用「導師」身分登入 → ⚙ 設定 →「人員設定」。每個工作範圍用下拉選單選同學，選過的人會自動從其他選單移除。選單內容來自雲端硬碟「外掃檢查照片」資料夾裡的名單試算表（需有「姓名」欄，可有「科別」「座號」）。
- 人員分配存在試算表的「工作分配」工作表，也可以直接在試算表裡修改。**GitHub 上不會出現任何同學姓名。**

> 3 位數字的密碼可以擋住一般人，但懂程式的人有機會試出來。想更安全可以換成較長的密碼。

## 測試模式

在密碼欄輸入 `test`，就會進入測試模式，可以模擬演練、看看效果：

- 名單的姓名中間以○遮住（例如「料15陳○琳」），去識別化，不會讀取雲端的真實名單。
- 地圖、標記、拍照、報表、切換使用人都能照常操作。
- **不能**儲存人員設定、傳送 LINE 通知、寫入試算表、上傳照片。
- 測試資料和正式資料分開存放。按上方的「結束測試」會清除測試資料，回到一般登入畫面。

## 換外掃區

修改 [`js/map-data.js`](js/map-data.js)：物件位置（0–1100）與工作範圍（jobs）。檔案開頭有欄位說明。

## 關於通知與隱私

- 「傳送通知」會開啟手機的分享選單，可直接傳到 LINE 班級群組。（LINE Notify 已於 2025 年停止服務，所以改用分享的方式。）
- 照片預設設為「知道連結的人可檢視」，網頁才能顯示大圖。若不希望如此，把 `Code.gs` 的 `SHARE_PHOTOS` 改成 `false`（在拍照的那支手機上仍可看大圖）。學校的 Google Workspace 帳號可能禁止公開分享，這種情況下照片仍會上傳，只是其他手機看不到大圖。
- 所有資料都存在你自己的 Google 帳號，網頁本身不會把資料傳給其他人。
