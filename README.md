# 外掃區檢查地圖

手機用的外掃區清潔檢查網頁。點地圖上的物件就能記錄清潔程度（好／不好／未出席）、標記「有狀況」、拍照上傳到 Google 雲端硬碟，並依紀錄彙整報表、通知同學，也會寫入 Google 試算表作為加扣分的依據。

- 純靜態網頁，可直接放在 **GitHub Pages**
- 後端使用 **Google Apps Script**（免費，資料存在你自己的 Google 帳號）
- 不設定雲端也能使用：紀錄只存在手機上

## 功能

| 功能 | 說明 |
|---|---|
| 長條地圖 | 走廊轉成直的，手機上下滑動。上＝南、下＝北、右＝西側（警衛室）、左＝東側（司令台） |
| 點選物件 | 點了才顯示物件名稱與負責同學，可記錄「好／不好／未出席」 |
| 有狀況 | 打開開關並寫下說明，地圖上會出現紅色閃爍外框和「!」旗標；上方的紅色標籤可以逐一跳到每個有狀況的地方 |
| 照片 | 手機端先壓縮（最長邊 1600px，約 150–300 KB）再上傳，小圖顯示在牆外空白處，點一下就能全螢幕檢視（可左右滑動） |
| 報表 | 按右下角的指南針：統計、需改進名單、有狀況清單、未檢查清單，可一鍵分享到 LINE、複製、寄 Email、寫入試算表 |
| 自動清空 | 從第一次標記開始算，20 小時後自動清空手機上的紀錄（試算表與雲端硬碟裡的資料會保留） |
| 離線可用 | 沒有網路時先存在手機裡，恢復連線後會自動補傳 |

右上角的圓點代表同步狀態：灰＝未設定雲端、綠＝都已寫入、黃＝等待寫入、藍＝寫入中、紅＝失敗（點一下可重試）。

## 一、放到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `outdoor-cleaning-map`），把這個資料夾的所有檔案上傳。
2. 到 repository 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 大約一分鐘後，網址會是 `https://你的帳號.github.io/outdoor-cleaning-map/`。用手機打開後，可以「加到主畫面」。

## 二、連接 Google 試算表與雲端硬碟

1. 建立一份新的 Google 試算表（例如「外掃檢查紀錄」）。
2. 選單 **擴充功能 → Apps Script**，把 [`gas/Code.gs`](gas/Code.gs) 的內容整份貼上，取代原本的程式碼。
3. 修改最上方的 `CONFIG`：
   - `TOKEN`：**一定要改**，自訂一組通關密碼
   - `NOTIFY_EMAILS`：要寄報表的 Email（可不填）
4. 上方函式選單選 `setup`，按「執行」，依畫面完成授權（會出現「Google 尚未驗證這個應用程式」，點「進階 → 前往」即可，這是你自己的腳本）。
   執行後試算表會多出「檢查紀錄」「每日彙整」「個人統計」三個工作表，雲端硬碟也會建立「外掃檢查照片」資料夾。
5. 右上角 **部署 → 新增部署作業**：
   - 類型：網頁應用程式
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 打開網頁，按右上角 ⚙ 設定，貼上網址、輸入通關密碼，按「測試雲端連線」。

> 之後若修改 `Code.gs`，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本** 才會生效。

也可以把網址寫進 [`config.js`](config.js) 的 `gasUrl`，這樣每支手機只需要輸入密碼。**通關密碼（TOKEN）不要寫進 GitHub 的檔案裡。**

## 試算表內容

- **檢查紀錄**：每個物件 × 每位負責同學一列（同一次檢查中修改會更新同一列，不會重複）
- **每日彙整**：在報表中按「寫入 Google 試算表」時產生，包含統計數字和通知訊息全文
- **個人統計**：自動統計每位同學「好／不好／未出席」的次數，可直接作為加扣分依據

## 密碼鎖與同學名單

打開網頁要先輸入密碼，每支手機輸入一次後就會記住（⚙ 設定裡可以「鎖定這支手機」）。

同學姓名**加密**存在 [`js/roster.enc.js`](js/roster.enc.js)，GitHub 上只看得到亂碼，輸入正確密碼後才會在手機上解開。

**修改名單或密碼：** 打開 `https://你的帳號.github.io/outdoor-cleaning-map/tools/roster.html`，輸入目前的密碼按「解開」，修改名單、輸入新密碼，產生加密檔後照頁面上的步驟貼回 GitHub 即可。

> 密碼越長越安全。3 位數字的密碼可以擋住一般人，但懂程式的人能在幾分鐘內試出來。

## 換外掃區

修改 [`js/map-data.js`](js/map-data.js)：區段、物件位置（0–1100）。檔案開頭有欄位說明。新增物件後，記得到名單工具幫新的 id 加上負責同學。

## 關於通知與隱私

- 「傳送通知」會開啟手機的分享選單，可直接傳到 LINE 班級群組。（LINE Notify 已於 2025 年停止服務，所以改用分享的方式。）
- 照片預設設為「知道連結的人可檢視」，網頁才能顯示大圖。若不希望如此，把 `Code.gs` 的 `SHARE_PHOTOS` 改成 `false`（在拍照的那支手機上仍可看大圖）。學校的 Google Workspace 帳號可能禁止公開分享，這種情況下照片仍會上傳，只是其他手機看不到大圖。
- 所有資料都存在你自己的 Google 帳號，網頁本身不會把資料傳給其他人。
